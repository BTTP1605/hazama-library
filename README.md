# はざまの図書館 ―停点あん内所―

『ヤコブの梯子』と『消えた踏切』への入り口となる、無料のチュートリアル兼トレーラー作品。
mystery-adv-builder スキル製。React + TypeScript + Vite、GitHub Pages公開、維持費ゼロ。

- 全編無料・解錠コードなし。プレイ時間 15〜20分
- 案内人（司書）が遊び方（テキスト送り・選択肢・手がかり収集・空欄嵌め推理）を教えながら、
  2作の世界をダイジェストで体験させる
- エンディング2種（両方の推理をノーミスで解くと真エンド「頁をめくる者」）

## セットアップ

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 型チェック + 本番ビルド
npm run deploy   # GitHub Pages へデプロイ
npm run gense    # 効果音を合成
npm run genimg   # 新規画像を Codex CLI で生成
```

## 構成

- 序章: 図書館と操作説明
- 第一頁「雨の物語」: 梯子の世界＋推理1
- 第二頁「踏切の物語」: 踏切の世界＋推理2
- 終章: 2作への案内＋エンディング

シナリオは `src/data/scenario/free/` の4ファイル。全編無料のため有料章・解錠画面は不使用
（`PAID_SCENE_IDS` は空、build から encrypt を除外済み）。

## アセット

背景（雨のコンビニ・旧線路・第四踏切）と立ち絵（梯子・紳士・宮田）は姉妹作から流用。
新規は案内人の立ち絵と図書館背景・タイトルキービジュアルのみ。
